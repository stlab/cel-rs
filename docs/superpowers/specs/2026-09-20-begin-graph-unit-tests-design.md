# Begin Graph Unit Tests Design

## Goal

Give `begin/assets/graph.js` contract-derived unit coverage for its pure geometry, graph
diffing, and viewport calculations, and make that test suite a required CI check.

## Boundaries

`window.beginGraph` remains the browser-facing API. The browser continues to load
`graph.js` as a classic script and does not gain a test-specific global API.

When CommonJS is present, `graph.js` exports only the documented pure helpers used by the
test suite. The browser path does not evaluate that export branch. This narrow seam lets
Vitest load the helpers without a DOM or D3 instance while keeping the production integration
unchanged.

## Contracts and Tests

Every extracted helper receives a JSDoc contract with its valid inputs and observable
postconditions. `GraphInstance` gains a type invariant describing the relationship between
its `nodes`, `links`, and `hiddenNodeIds` collections at public method boundaries.

Tests call only the exported helper interface and assert its contracts:

- rectangle, circular, and branch link endpoints lie on their documented boundaries;
- degenerate source/target positions have their specified stable endpoint;
- graph bounds include visible-node geometry and the fit margin, while an empty visible graph
  returns the viewport bounds;
- fitting centers content in the viewport and chooses the smaller axis scale;
- link and node structure comparisons distinguish topology changes from value-only updates;
- updating a node with a retained identifier preserves its identity and position, while a
  changed label is reported for remeasurement.

Tests do not inspect the source or assert implementation-specific collections, callbacks, or
D3 calls. If an intended behavior cannot be stated as an interface contract, the helper is
redesigned until it can.

## Tooling and CI

`begin/package.json` adds Vitest and a one-shot `test` script. Tests live in
`begin/js/graph.test.js` and import CommonJS exports from `begin/assets/graph.js`.

CI installs the `begin` Node dependencies with `npm ci` and runs `npm test` before its Rust
checks. `begin/assets/swc.js` remains a generated Spectrum bundle and is not regenerated by
this change.

## Project Rule

`CLAUDE.md` states that every class, type, and function in every repository language needs an
adjacent contract. A contract names its valid inputs or type invariants, observable results,
errors, and relevant complexity. Tests derive only from that contract and the public interface;
needing an implementation detail is evidence that the contract or interface needs clarification.
