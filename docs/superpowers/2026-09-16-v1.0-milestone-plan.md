# v1.0 Milestone — Independent Work Groups

Original grouping as of 2026-09-16; completion reviewed on 2026-10-23 against GitHub issue/PR
status, repository code, and implementation handoffs. This organizes the 12 issues that were
open in the `v1.0` milestone into groups that can be worked on independently (each group in its own worktree/PR
sequence) with minimal expected merge conflict, and orders the groups so that anything other
groups build on lands first. Within a group, issues are listed in the order they should land
if the group's issues touch overlapping code (noted per group); across groups with no listed
dependency, the groups themselves can proceed in parallel.

Checked items are implemented or explicitly resolved as noted; a closed duplicate or
not-planned issue does not mean its original proposal was implemented. Partial work remains
unchecked. All completed implementations below are merged. Group 4's issues were closed
after verifying the existing implementations on 2026-10-23; no duplicate implementation
was needed. The milestone's remaining open issues are #186, #29, #258, and #259.
Groups 8 and 9 add scope requested on 2026-10-23 to the original grouping.

Gaps found in `docs/VISION.md`'s roadmap that had no tracking issue were opened separately
during this review: #218 (query pinned cells), #219 (cell "memory"/unlink behavior), and #220
(view-constraint sheets, blocked on #109/#110/#111). They are not v1.0-milestoned and are not
included in the groups below.

grammar entry points) that sequencing it between #110 and #111 avoids a three-way conflict;
it could equally be reordered first if that better matches whoever picks up this track.
Fully independent of Groups 1–3 (different crates entirely — no shared files with `adam-rs` or
`begin`).

## Group 5 — parameterized sheets and relationship composition

- [ ] #29 — explicitly typed, reusable sheets with named cell bindings. Scope
  revised on 2026-10-25: compose authored relationships and private cells rather
  than infer directional methods from equations. The approved implementation
  and public contract tests are present in the linked worktree, with the local
  full-gate evidence recorded in the
  [2026-10-26 handoff](2026-10-26-parameterized-sheets-handoff.md).
  The independent whole-branch review found one Important and two actionable
  Minor findings. The consolidated local fix wave addresses conditional runtime
  provenance, namespace consistency and this status record. The scoped re-review
  approved all three fixes with no open findings on 2026-10-27. Publication
  remains pending; #29 stays open.

Support inline definitions, Rust-like `use` over client-supplied modules, and
programmatic template construction without parsing. Caller cells retain their
filters and requirements. Source bindings discard whole methods that write them;
diagnose relationships with no remaining methods and repeated actual cells.
Bodies support private cells/sources/outputs, conditionals, and nested uses.
Inside a caller's conditional branch, only relationship-only components are
allowed initially: no private cells or conditionals. Diagnose other uses;
relaxing this restriction is deferred to #264 outside v1.0.

The approved design expands templates into the caller's planning graph with
fresh private cells. See
`docs/superpowers/specs/2026-10-25-parameterized-sheets-design.md` and the
implementation plan at `docs/superpowers/plans/2026-10-25-parameterized-sheets.md`.
The scope spans
library construction APIs, `adam-lang`, and language tooling, so it is no longer
assumed to be confined to parser/AST changes. Coordinate with Groups 8 and 9.
Out-cell arguments (#261), language generics (#262), and inline equations with
direction inference (#263) are deferred outside v1.0.
